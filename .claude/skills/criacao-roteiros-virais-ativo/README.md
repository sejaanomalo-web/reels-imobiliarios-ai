# Skill Mestre Editorial da ATIVO — Guia de Navegação

**Antes de tudo:** verificar `modelos/` (em minúsculas), rodar `python3 modelos/verificar_pendentes.py` e priorizar referências MP4 pendentes segundo `modelos/PROTOCOLO_DE_ANALISE.md`. Se houver referência pendente, analisar e propor adaptação original antes da pesquisa de ideias livres. O usuário com o Claude Code define os estilos visuais finais; aqui só sugerimos aprimoramentos de roteiro/direção.

Esta pasta complementa, não substitui, o CLAUDE.md do repositório. Trata **criação de novos roteiros**; as skills de estilo tratam **como transformá-los em vídeo**.

- SKILL.md: índice, regras vigentes, ordem de execução, limites.
- etapas/01...10: um manual por fase, com entradas, procedimentos, critérios, rejeições e saídas.
- MODELO_DE_ENTREGA.md: contrato de saída completo, utilizável por gravação e Remotion.
- EXEMPLOS_E_ANTIPADROES.md: aprendizados do primeiro teste rejeitado e da direção aprovada, sem transformar o exemplo em fórmula.
- PROMPT_DE_EXECUCAO.md: mensagem para iniciar um trabalho editorial no Claude Code.

**Para usar:** abra o repositório no Claude Code e solicite explicitamente a skill criacao-roteiros-virais-ativo. Leia todos os arquivos pertinentes e siga os pontos de aprovação.

**Prioridade de contexto:** decisões explícitas do usuário na tarefa atual > regras mais recentes desta Skill para novos roteiros > guias editoriais antigos > modelos de estilo para produção. Regras de segurança, veracidade e licenciamento não podem ser ignoradas.

**O que NÃO faz:** render automático, alterações em vídeos publicados, pagamentos, ferramentas de previsão viral. A saída passa para a produção existente só quando solicitada e aprovada.
